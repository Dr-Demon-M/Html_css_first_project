# HTML & CSS — First Project

A responsive one-page website template built with **pure HTML5 and CSS3** — no frameworks, no JavaScript. First practice project in a series of three.

## Sections

- Header with navigation
- Landing / hero
- Services
- Portfolio
- About
- Contact

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox / Grid, media queries)
- [Normalize.css](https://necolas.github.io/normalize.css/) for cross-browser defaults
- Font Awesome icons
- Google Fonts (Work Sans, Lateef)

## Run it

No build step needed:

```bash
git clone https://github.com/Dr-Demon-M/Html_css_first_project.git
cd Html_css_first_project
```

Then open `index.html` in a browser — or serve it with any static server (e.g. VS Code **Live Server**).
